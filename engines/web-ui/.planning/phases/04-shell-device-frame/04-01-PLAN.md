**DeviceFrame component** (`src/components/shell/DeviceFrame.tsx`):

Props: `{ deviceType: 'phone' | 'tablet' | 'desktop'; children: React.ReactNode }`

Structure (all divs with CSS Module classes):
```
<div class="frame frame--{deviceType}">       <!-- outer bezel -->
  {deviceType === 'phone' && <div class="dynamicIsland" />}
  <div class="content">                        <!-- container query host -->
    {children}
  </div>
  {deviceType === 'phone' && <div class="homeIndicator" />}
  {deviceType === 'desktop' && <div class="titleBar">...</div>}  <!-- at top, before content -->
</div>
```

Export `DeviceType` as a type: `'phone' | 'tablet' | 'desktop'`.

**FrameSwitcher component** (`src/components/shell/FrameSwitcher.tsx`):

Props: `{ value: DeviceType; onChange: (type: DeviceType) => void }`

Renders an iOS-style segmented control with three segments: Phone, Tablet, Desktop.

Structure:
```
<div class="switcher">
  <div class="highlight" style="transform: translateX({offset})" />  <!-- sliding bg -->
  <button class="segment {active}" onClick={...}>Phone</button>
  <button class="segment {active}" onClick={...}>Tablet</button>
  <button class="segment {active}" onClick={...}>Desktop</button>
</div>
```

The sliding highlight is a `::before` pseudo-element OR a positioned div that transitions to the active segment position. Use `transform: translateX()` with `transition: transform 200ms ease` for smooth slide.

Compute highlight offset: index * segmentWidth (each segment is 33.33%).

- `.segmentActive`: `color: #000; font-weight: 600;`
- Inactive segments: `color: #666;`
