**1. Create src/manager/WorkflowManagerContext.tsx:**
- Create two contexts: `WorkflowManagerContext` (for WorkflowManager) and `HistoryStoreContext` (for HistoryStore), both defaulting to null.
- Create `WorkflowManagerProvider` component that:
  - Uses `useMemo` to create a single WorkflowManager and HistoryStore instance (pass history store to manager constructor)
  - Provides both via nested context providers
  - Accepts `children: ReactNode`
- Follow the same pattern as existing WorkflowContext.tsx (createContext + Provider component).

**2. Create src/manager/useWorkflowManager.ts:**
- `useWorkflowManager()` -- reads WorkflowManager from context, throws if missing. Returns the manager instance (for calling addWorkflow, removeWorkflow, etc.).
- `useManagerSnapshot()` -- full snapshot subscription via useSyncExternalStore(manager.subscribe, manager.getSnapshot). Returns ManagerSnapshot.
- `useManagerSelector<T>(selector: (snap: ManagerSnapshot) => T): T` -- selector-based hook with useRef memoization to prevent re-renders when selected value hasn't changed. Pattern from RESEARCH.md:
  - Store previous value in useRef
  - Store selector in useRef (update every render to avoid stale closure)
  - In getSnapshot callback: compute `next = selector(manager.getSnapshot())`, compare with `Object.is(prev, next)`, return prev ref if equal
  - Use useCallback with [manager] dependency for stable getSnapshot function
- `useActiveCount()` -- convenience: `useManagerSelector(s => s.activeCount)`
- `useFocusedId()` -- convenience: `useManagerSelector(s => s.focusedId)`

**3. Create src/manager/useActiveCoordinator.ts:**
- `useCoordinatorById(id: string | null)` -- subscribes to a specific coordinator's snapshot by workflow ID. Returns CoordinatorSnapshot | null. Pattern from RESEARCH.md:
  - Get manager from context
  - subscribe callback: if no id, return noop cleanup. Get coordinator via manager.getCoordinator(id). If no coordinator, return noop. Return coordinator.subscribe(cb).
  - getSnapshot callback: if no id, return null. Get coordinator, return coordinator?.getSnapshot() ?? null.
  - Both wrapped in useCallback with [manager, id] deps
  - Pass to useSyncExternalStore
- `useActiveCoordinator()` -- convenience that gets the focused ID from manager and subscribes to that coordinator. Uses useFocusedId() + useCoordinatorById(focusedId). Returns CoordinatorSnapshot | null.

**4. Create src/manager/useHistory.ts:**
- `useHistory()` -- full history subscription: useSyncExternalStore(store.subscribe, store.getSnapshot). Returns HistoryEntry[].
- `useHistorySelector<T>(selector: (entries: HistoryEntry[]) => T): T` -- same useRef memoization pattern as useManagerSelector.
- `useHistoryCount()` -- convenience: `useHistorySelector(entries => entries.length)`
- Read HistoryStoreContext, throw if missing.

All hooks import from React: useContext, useCallback, useRef, useSyncExternalStore. Import types from './types'. Import contexts from './WorkflowManagerContext'.
