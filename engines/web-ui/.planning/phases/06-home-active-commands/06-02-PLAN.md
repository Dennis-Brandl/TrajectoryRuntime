**Install dependency:**
Run `npm install embla-carousel-react` before any code changes.

**ActiveStepCard component (src/components/ActiveStepCard.tsx):**
Renders a single step within the step carousel. Dispatches between three rendering modes based on step state:

1. **Interactive mode** (state === 'EXECUTING' and stepType is 'YES_NO' or 'USER_INTERACTION'):
   - Render StepRenderer component (from ../StepRenderer) with full form interaction
   - Pass step, onAction, properties, inputParameters, mediaMap from coordinator snapshot
   - onAction calls coordinator.submitAction via the manager

2. **Disabled mode** (state === 'WAITING' or 'PAUSED'):
   - Render StepRenderer but wrap in a div with `pointerEvents: 'none'` and `opacity: 0.5`
   - Show a small banner at top: "Waiting..." or "Paused" in muted text

3. **Info card mode** (state is 'HELD', 'POSTED', 'RECEIVED', 'IN_PROGRESS', or 'ABORTED'):
   - Render a calm light blue card (background: #e8f4fd or similar)
   - Show: step label (step.step.description or stepType), step state (formatted: replace underscores with spaces), timestamp
   - Timestamp: use a useRef<Map<string, number>> to capture Date.now() when step first appears in a given state. Key: `${step.oid}:${step.state}`. Format as time string (HH:MM:SS).

4. **Auto-completing types** (stepType not YES_NO or USER_INTERACTION, state === 'EXECUTING'):
   - Show info card style with step label and "Processing..." text
   - These steps auto-complete via the engine, no user interaction needed

**Props interface:**
```typescript
interface ActiveStepCardProps {
  step: ActiveStepInfo;
  onAction: (action: UserAction) => void;
  properties: Record<string, string>;
  inputParameters: Record<string, string>;
  mediaMap: Record<string, string>;
}
```

- .disabledOverlay: pointer-events none, opacity 0.5
